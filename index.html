MISSION 01
Claims analytics app
In daily use

A rules engine that tells the claims team which files are stuck — and why.

The claims team tracked every file in a shared spreadsheet and followed up by hand. I built a full-stack web app that reads that file live and classifies every claim — the game above is a tiny version of it.

  • 7 business rules defined with the claims department decide whether each file is settled or not.
  • Python, FastAPI and Pandas on the back end; Chart.js dashboards on the front end.
  • Runs on the company's local network, so client data never leaves the office.
